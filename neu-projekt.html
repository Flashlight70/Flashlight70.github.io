Einbauen

  1. Bilder nach assets/<id>/ legen. Grosse Bilder vorher auf etwa 1600 px Breite verkleinern und als JPG speichern, sonst lädt die Seite langsam.
  2. Erzeugten Block kopieren.
  3. projects.json öffnen, den Block als neues Element in die Liste projects einfügen. Zwischen zwei Einträgen steht immer ein Komma.
  4. Im Ordner: git add ., git commit -m "Add project <id>", git push
  5. Nach etwa einer Minute ist es online. Vorher lokal prüfen mit python -m http.server und localhost:8000.
